# SENTINEL SOC — UI/UX Prototype

A high-fidelity Secure Operations Center (SOC) dashboard designed to monitor and protect a server enclosure through real-time telemetry, tamper detection, authentication, and remote data-line control.

## Features

- Real-time Li-Fi optical link monitoring
- Signal strength and link-quality visualization
- Layer 2/3 bus-voltage monitoring
- Surge/warning status indicators
- Layer 4 chassis tamper detection
- Instant security breach alerts
- Administrator token authentication
- Remote data-line unlock/isolation controls
- Security event monitoring
- Audit logs
- Responsive desktop and mobile interface
- Interactive telemetry charts
- Dark cybersecurity-focused UI
